# Site Oficial - Igreja Missionária Evangélica Betel Jaguaribe

Projeto web moderno, ágil e de fácil manutenção desenvolvido para a **Igreja Betel em Jaguaribe, João Pessoa - PB**.

## 📍 Localização
- **Endereço:** Rua Engenheiro Leonardo Arcoverde, 145 — Bairro Jaguaribe, João Pessoa - PB
- **Ponto de Referência:** Próximo ao Hemocentro da Paraíba
- **Redes Sociais:** [@beteljaguaribe](https://www.instagram.com/beteljaguaribe/)

## 🛠️ Tecnologias Utilizadas
- **HTML5 Semântico:** Estruturação limpa, acessível e otimizada para SEO.
- **Tailwind CSS (via CDN):** Design responsivo contemporâneo sem necessidade de compilação ou Node.js.
- **Vanilla JavaScript (ES6+):** Lógica dinâmica, cálculo inteligente do próximo culto em tempo real e integração com Clipboard API.
- **Lucide Icons & Google Fonts:** Tipografia moderna (Outfit e Plus Jakarta Sans) e ícones minimalistas.
- **conteudo.js (CMS Simplificado):** Arquivo centralizado onde leigos podem editar textos, cultos, eventos e PIX sem risco de quebrar o site.

## 🚀 Como Executar Localmente
Dê um duplo clique no arquivo:
```
Iniciar_Site_Local.bat
```
Ou simplesmente abra o arquivo `index.html` em qualquer navegador.

Consulte o arquivo [`Como_Editar_O_Site.md`](Como_Editar_O_Site.md) para o guia detalhado de manutenção e publicação online.
